## Prerequisites

- Python 3.10 or later
- [uv](https://docs.astral.sh/uv/getting-started/installation/) package manager

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/dharc-org/changes-metadata-manager.git
cd changes-metadata-manager
uv sync
```

## Input data

The tool expects two things to be in place before you run it:

1. A **knowledge graph** in Turtle format at `data/kg.ttl`. This file is generated by [morph-kgc-changes-metadata](https://github.com/dharc-org/morph-kgc-changes-metadata) and contains all the RDF triples describing the digitized objects.

2. A **folder structure** following the pattern `Sala*/Folder/Stage/`, either on the local filesystem or described in a JSON file exported from SharePoint. See the [digitization stages](/changes-metadata-manager/reference/stages/) page for what each stage represents.

## Quick start

Once you have the knowledge graph and the folder structure, generate metadata and provenance for all objects:

```bash
uv run python -m changes_metadata_manager.folder_metadata_builder /path/to/root
```

If you are working from a SharePoint export instead of a local filesystem:

```bash
uv run python -m changes_metadata_manager.folder_metadata_builder /path/to/root \
    --structure data/structure.json
```

Each stage folder will receive:
- `meta.ttl`: RDF metadata extracted from the knowledge graph
- `prov.trig`: provenance snapshots in TriG format

## Running tests

```bash
uv run pytest
```

With coverage reporting:

```bash
uv run pytest --cov=changes_metadata_manager --cov-report=term
```
